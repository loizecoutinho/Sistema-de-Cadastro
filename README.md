# Sistema-de-Cadastro

Este projeto foi uma oportunidade prática de aplicar conceitos de POO, interfaces, persistência de dados e integração entre camadas, fortalecendo a compreensão sobre o fluxo completo de uma aplicação desktop conectada a banco de dados.

♨️ Sobre a Aplicação

O Sistema de Cadastro é uma aplicação Java desenvolvida como projeto final da disciplina de Programação Orientada a Objetos na Universidade Estadual do Piauí (UESPI).

O sistema tem como objetivo gerenciar o cadastro de alunos, integrando interface gráfica (Swing), persistência de dados (Hibernate) e manipulação em memória (Collections).
A aplicação realiza o cadastro, listagem e exclusão de alunos, armazenando as informações tanto em uma ArrayList quanto em um banco de dados MySQL via Hibernate e em um Arquivo txt.

✨ Funcionalidades Implementadas

Telas de Cadastro: Interface principal desenvolvida em Swing (JFrame) para inserção dos dados dos alunos, com integração direta ao banco de dados.

Tela de Leitura do Arquivo: Exibição dos alunos cadastrados em uma JTable, permitindo a visualização dos registros armazenados no arquivo

Interface AlunoDAO: Define o método responsável pela remoção de alunos, implementado em uma classe que gerencia as operações de exclusão.

Integração com Banco de Dados: Implementada com Hibernate, permitindo a persistência automática dos dados no MySQL Workbench.

Estrutura de Dados: Utilização de Collections (ArrayList) para gerenciamento dos objetos Aluno durante a execução, facilitando operações de busca, listagem e exclusão antes da persistência no banco.

🛠️ Tecnologias Utilizadas

Linguagem de Programação: Java

Framework/Biblioteca: Collections, Hibernate, Swing

Banco de Dados: MySQL (MySql Workbench).
